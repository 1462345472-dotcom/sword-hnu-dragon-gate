## 五、抽审样题(每种题型 2 道)

**choice(#34, 985 真题风格)**
> 在鱼藤酮存在的情况下,1 分子琥珀酸经呼吸链氧化生成的 ATP 数约为?
> A 0 个 / B 1.5 个 / C 2.5 个 / D 4 个 —— 答案 B。鱼藤酮抑制复合体 I(NADH→CoQ),琥珀酸经复合体 II 进入呼吸链不受影响,仍产生约 1.5 个 ATP。

**choice(#29, 复合体 IV 细节)**
> 复合体 IV 中电子传递的正确顺序是?
> A Cyt c→血红素 a3→CuB→血红素 a→O₂ / B Cyt c→CuA→血红素 a→血红素 a3-CuB→O₂ / C O₂→血红素 a3→CuA→Cyt c / D NADH→FMN→Fe-S→O₂ —— 答案 B。

**truefalse(#67, 抑制剂分类辨析)**
> 氧化磷酸化抑制剂寡霉素直接作用于呼吸链上的电子载体,抑制电子传递。—— 错。寡霉素堵塞 Fo 质子通道直接干扰 ATP 生成,不直接抑制电子载体,电子传递受阻是偶联后果。

**truefalse(#27, 特性辨析)**
> 细胞色素 c 是呼吸链中唯一能溶于水的细胞色素。—— 对。

**multi(#14, 跨知识点计算)**
> 关于呼吸链复合体泵出质子数(每传递一对电子),下列说法正确的有?A 复合体 I 泵 4 个 H⁺ / B 复合体 II 泵 0 个 / C 复合体 III 泵 4 个 H⁺ / D 复合体 IV 泵 2 个 H⁺ / E 复合体 II 泵 4 个 H⁺ —— 答案 ABCD。

**multi(#98, 两种穿梭比较)**
> 关于甘油-3-磷酸穿梭与苹果酸-天冬氨酸穿梭的比较,正确的有?(器官分布、进入链的电子载体、可逆性、产能 1.5 vs 2.5、均使胞质 NADH 电子入链)—— 答案 ABCDE。

**short(#84, 结合变构机制)**
> 简述 ATP 合酶结合变构机制的主要内容:①T/L/O 三态与功能;②合成不需质子驱动力、释放需要;③γ 亚基转动驱动构象循环;④每 3 个质子转 120°、3 个 β 亚基各经历一次构象变化释放 1 个 ATP。

**short(#88, 穿梭过程)**
> 简述甘油-3-磷酸穿梭的过程、场所与产能:胞质 3-磷酸甘油脱氢酶(NAD⁺)→3-磷酸甘油入内膜→线粒体 3-磷酸甘油脱氢酶(FAD)→磷酸二羟丙酮回胞质→FADH₂ 传电子给 CoQ→约 1.5 个 ATP,见于肌肉和脑。
