# 题库导入实施计划

> **For agentic workers:** 使用 parallel agents 执行内容生成，每章独立并行。使用 `/code-review` 审查 JSON 改动。

**Goal:** 从 DOCX 章节笔记生成题目并导入题库，覆盖生化5-14章 + 细胞3-16章

**Architecture:** 4批流水线，每批并行 agent 读 DOCX → 对照考纲 → 生成 JSON → 验证 → 下一批

**Tech Stack:** Python (python-docx 校验), JSON, 现有题库 HTML 加载测试

## Global Constraints

- JSON 格式必须与现有 `questions.json`/`terms.json` 兼容
- 题目 ID 从1开始自增，choice/truefalse/multi/short 共用一个 ID 序列
- 不修改题库 HTML 核心逻辑
- 每个考纲知识点至少3题
- 不出时间/年代类选择题
- 简答题分点结构，名词解释30-80字

---

## File Structure

```
生物化学题库/第X章/
  questions.json    ← 生成（选择+判断+多选+简答）
  terms.json        ← 生成（名词解释）

细胞生物学题库/第X章/
  questions.json    ← 生成
  terms.json        ← 生成
```

- 不修改: `湖南大学题库(1).html`（章节注册已完成）
- 不修改: `src_js.txt`, `src_css.txt`, `build_unified.py`

**Files:**

- Modify: `生物化学题库/第五章/terms.json`

**考纲对应:** 338 考纲专题3「蛋白质」— (5)蛋白质的理化性质及分离纯化和纯度鉴定方法、(6)蛋白质的变性作用、(7)蛋白质结构与功能的关系

**参考:** 高校338真题中蛋白质分离纯化相关题型

**Interfaces:**
- Produces: questions.json（~30-50题：选择+判断+多选5+简答5-8），terms.json（~10-15条名词解释）

- [ ] **Step 1: 精读 DOCX** — 提取全部知识点、重点标注、表格内容、考频星级
- [ ] **Step 2: 对照考纲** — 确认覆盖：(5)分离纯化方法（盐析、层析、电泳等）、(6)变性因素与机制、(7)结构与功能关系（肌红/血红蛋白）
- [ ] **Step 3: 生成选择题+判断题** — 每个知识点2-4题，多维度（概念辨析、方法对比、实验设计、结果判读）
- [ ] **Step 4: 生成多选题** — 5道以上，综合考察（如"关于蛋白质变性的正确说法有哪些"、"下列哪些方法用于蛋白质分离纯化"）
- [ ] **Step 5: 生成简答题** — 5-8道，分点结构，如"简述蛋白质盐析的原理及影响因素（分点作答）"
- [ ] **Step 6: 生成名词解释** — 10-15条，如"盐析、等电点沉淀、凝胶过滤层析、SDS-PAGE、蛋白质变性"
- [ ] **Step 7: JSON 格式校验** — `python3 -c "import json; json.load(open('questions.json')); print('OK')"`
- [ ] **Step 8: ID 连续性校验** — 确认 questions.json 内 ID 从1连续递增，terms.json 同
