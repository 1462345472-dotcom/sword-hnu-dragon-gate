# 生化 15-36 章出题导入设计

- 日期: 2026-08-07
- 状态: 已与用户逐节确认(brainstorming 流程)
- 目标文件: 生物化学题库/湖南大学题库系统-臻至版.html(唯一数据宿主)

## 1. 背景与目标

湖南大学考研题库系统(338 生物化学 + 851 细胞生物学,单文件 HTML)已完成数据层构建:29 个章节对象、2549 题、516 术语(经三重独立验证:HTML 数组长度 = stats 字段 = 文件夹 json,0 处不一致)。

**唯一缺口:生物化学第 15~36 章(22 章)完全没有数据。** 各章扫描版课件 PDF 已就绪,本文设计其"识别 → 出题 → 导入"全流程。

## 2. 范围与约束

- **只改数据,不动 UI**:CSS、HTML 结构、已有章节对象一律不碰;UI 改动零容忍
- **唯一数据源**:臻至版 HTML;章节 questions.json 只是导出副本
- **去重**:新题与 HTML 已有 2549 题比对,重复题剔除或改写
- **备份由用户自行管理**(用户明确要求,不做自动备份);但保留 CSS 指纹检测(纯对比,不复制文件)

## 4. 完整流水线(每章 7 步,试点跑通后复用)

```
① 分色 OCR   扫描 PDF → 300dpi 渲染 → 红字/黑字像素分离 → 分别识别
              → 输出全文文本 + 【红·重点】标记段
② 考纲对照   从已识别《338生物化学考纲》提取本章相关考点 → 考点清单
              (宗旨:考纲第一中的第一,一个考点都不漏)
③ 出题        按 12 条质量标准和 985 高校真题风格生成题目
              (4 题型;红字重点考点题量 ×2;题量按篇幅线性;不出年代题)
④ 生成数据   questions.json + terms.json(与 1-14 章同格式)
⑤ 校验+去重  schema 校验 + 与 HTML 2549 题去重比对
⑥ 导入        写入臻至版 HTML 的 biochem_NN 章节对象 + CHAPTER_NAMES + stats
⑦ UI 验证      CSS 指纹前后对比(必须完全一致)+ 做题功能抽查
```

## 5. 出题规则落地(12 条质量标准)

| 标准 | 落地方式 |
|------|---------|
| 考纲全覆盖(第一中的第一) | 考点清单逐条打勾,漏考点强制补题后才放行 |
| 红字/⭐ 权重 | 考点标注来源(红/⭐/普通),红字考点题量 ×2;无标记考点不遗漏 |
| 题型 → 模块映射 | choice/truefalse→全部刷题;multi→多选专项;short→简答模板;名词解释→terms |
| 多维度出题 | 同考点列出可出角度(定义/特点/机制/举例/对比),每题角度不同 |
| 多选跨知识点 | 多选题选项取自 ≥2 个知识点 |
| 简答分点精炼 | 答案强制 ①②③ 分点结构,不照抄原文 |
| 名词解释 30-80 字 | definition 长度自动校验 |
| 985 高校真题参考 | 出题时参照中科大/浙大/武大等 985 生化真题的设问角度、难度分布、选项设计,抽审时呈现参照 |
| 不出时间/年代选择题 | 生成时过滤 + 抽审双保险 |
| 动态题量 | 按 OCR 后章节篇幅线性计算,与 1-14 章平均密度对齐 |
| Matt Pocock 技能监督 | 出题脚本走 code-review;生成数据跑 schema 校验 |
| 别搞崩题库 | 只插入新对象;指纹检测;任何异常立即停,先诊断再继续 |

优先级:**考纲 > 红色重点 > 黑色正文**。

## 6. 数据格式与导入方式

目标结构与现有章节对象完全同构:

```json
"biochem_15": {
  "key": "biochem_15",
  "name": "生物化学",
  "code": "338",
  "chapterLabel": "15 新陈代谢总论",
  "questions": [
    {"id":1,"type":"choice","question":"…","options":{"A":"…","B":"…","C":"…","D":"…"},
     "answer":"B","explanation":"…","difficulty":2,"tags":["…"],"topic":"…"}
  ],
  "terms": [
    {"id":1,"term":"…","name":"…","definition":"…","chapter":"biochem_15"}
  ],
  "stats": {"total":N,"choice":N,"truefalse":N,"multi":N,"short":N,"terms":N}
}
```

导入细节:
- 插入位置:紧随 biochem_14 之后(生化区)
- 同步更新 CHAPTER_NAMES 显示名
- stats 由脚本自动统计
- 题目 id 章节内从 1 编号;topic 标记考点归属
- 写入后跑结构一致性检测(全部对象重新解析,数字与 stats 互证)
- 文件夹 questions.json 同步导出副本

## 7. 质量关卡与安全网

| 关卡 | 时机 | 内容 |
|------|------|------|
| 用户抽审 | 每章出题后、导入前 | 每种题型抽看 1-2 道(题干/选项/答案/解析 + 985 真题参照),认可才导入 |
| 考纲核对 | 同上 | 考点清单逐条打勾 |
| schema 校验 | 导入前 | 类型/必填字段/答案合法性/名解长度 |

UI 保障:导入前后 CSS 指纹完全一致;只插入一个数据对象。
回滚:用户自备备份;指纹检测失败或功能异常 → 用户恢复备份 → 重新核对。
