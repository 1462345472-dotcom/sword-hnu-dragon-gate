# 题库导入设计文档

**日期**: 2026-08-04
**主题**: 从 DOCX 章节笔记批量导入题目到湖南大学考研题库

---

## 1. 背景与目标

湖南大学考研题库（338生物化学 + 851细胞生物学）已完成前4章（生化1-4章）和前2章（细胞1-2章）的题目录入。现需将其余章节（生化5-14章，细胞3-16章）的题目从机构提供的DOCX精炼笔记中导入。

核心原则：题库是考研速成工具，题目要精炼、有结构、重点突出。

## 2. 数据源

| 数据源 | 用途 |
|--------|------|
| DOCX章节笔记 | 主要出题依据，含表格、重点标注、考频星星 |
| 338/851考纲 | 覆盖范围约束，确保每个考点有题 |
| 高校真题（网上） | 参考出题维度和难度 |

## 3. 题型与入口映射

| 题型 | JSON type | 题库入口 | 说明 |
|------|-----------|----------|------|
| 单选题 | `choice` | 全部刷题 | 四选项，A/B/C/D |
| 判断题 | `truefalse` | 全部刷题 | true/false |
| 多选题 | `multi` | 多选专项 | 综合性强，跨知识点 |
| 简答题 | `short` | 简答模板 | 分点精炼，不照抄 |
| 名词解释 | term(terms.json) | 名词解释 | 30-80字精炼定义 |

## 4. JSON 格式

### questions.json
```json
{
  "id": 1,
  "type": "choice|truefalse|multi|short",
  "question": "题干",
  "options": {"A":"...","B":"...","C":"...","D":"..."},
  "answer": "A|true|false|分点答案文本",
  "explanation": "解析说明",
  "difficulty": 1,
  "tags": ["高频考点"]
}
```

### terms.json
```json
{
  "id": 1,
  "name": "术语名",
  "definition": "精炼定义（30-80字）"
}
```

## 5. 出题规则

### 5.1 数量原则
- 每个考纲知识点至少3题，多维度考察
- 同一知识点可换角度重复出题（正向问、反向问、场景化问）
- 数量不设上限，以DOCX内容量为准

### 5.2 权重分配
- DOCX标注★的重点/高频内容：多出（4-6题/知识点）
- 未标注的常规内容：适量（2-3题/知识点）
- 低频考点：覆盖但不深入（1-2题/知识点）
- 不出时间/年代类选择题

### 5.3 各题型要求
| 题型 | 特殊要求 |
|------|----------|
| 选择题 | 多角度，干扰项要有迷惑性 |
| 判断题 | 考易混淆概念 |
| 多选题 | 跨知识点联动，区分理解深度的综合性题目 |
| 简答题 | 分点结构，提炼精华，速成版 |
| 名词解释 | 一句话抓核心，不照抄原文 |

### 5.4 禁止项
- 不出时间/年代类选择题
- 简答/名解不照抄DOCX原文
- 不超出考纲范围

## 6. 执行计划

### 分批流水线

| 批次 | 科目 | 章节 | 章节数 | 备注 |

| 1 | 生化 | 5-9 | 5 | 蛋白质性质→糖代谢 |

### 每批流程
1. 并行 agent 精读 DOCX → 提取知识点、重点标注、考频
2. 对照考纲 → 确认覆盖范围
3. 生成题目 → 分题型写入
4. JSON 验证 → 格式校验
5. 集成测试 → 确认题库加载正常

### 质量保证
- 每章出题后校验 JSON 格式
- 使用 `/code-review` 审查代码改动
- 不搞崩题库系统
