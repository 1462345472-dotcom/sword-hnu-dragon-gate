2. **细胞补题至两科均衡**:细胞 1505 → ~3000 题(两科比例 ~47:53)
3. 全程 UI 零改动、不崩溃、每章备份

## 5. 每章重审流水线(5 步)

```
① 自动扫描   脚本逐题扫描生成疑点清单:
              - 格式问题(字段缺失/answer非法/id不连续/名解超字数)
              - 知识疑点(选项重复/答案与解析矛盾/年代类表述)
              - 考纲缺口(本章考纲考点 vs 现有题目 topic 对比)
② 全量重审   agent 带 12 条标准 + 疑点清单逐题判定:
              合格→保留;可修→修正;救不了→删除重出;考纲缺口→补新题
③ 自检+查重   schema 校验 0 违规 + 跨章查重 0 重复
④ 抽验导入   主会话抽验 → 更新臻至版 HTML 该章对象 + stats + 备份"…优化版.html"
⑤ 验证提交   指纹一致 + 浏览器加载检查 + git 提交
```

## 6. 重审判定细则(12 条标准逐题检查)

| # | 检查项 | 判定标准 | 不合格处理 |
|---|--------|---------|-----------|
| 1 | 知识正确性 | 与考纲教材(生化朱圣庚第四版/细胞丁明孝第五版)一致 | 修正答案/解析;整体错→重出 |
| 2 | 考纲覆盖 | 本章考纲考点都有题(topic 标注) | 缺口补新题 |
| 3 | 题型映射 | type 正确归属 | 修正 type |
| 4 | 多维度 | 同考点多题角度不同 | 重复角度→改写其一 |
| 5 | 多选跨知识 | multi 选项跨 ≥2 知识点 | 改写选项 |
| 6 | 简答分点 | short 答案 ①②③ 分点精炼 | 重写答案 |
| 7 | 名解长度 | definition 30-80 字 | 扩写/压缩 |
| 8 | 题干质量 | 题干清晰无歧义、选项不重复、干扰项合理 | 改写或重出 |
| 9 | 解析质量 | 解析有实质内容 | 空洞→补写 |
| 10 | 无年代题 | 选择题不含时间/年代类考点 | 改写 |
| 11 | 教材依据 | 内容以考纲教材为准 | 修正 |
| 12 | 格式合法 | 字段齐全/答案合法/id 连续 | 修字段 |

删除重出规则:题干与解析都含糊、或知识性硬错无法定位正确内容 → 删除,按该考点重新出题补位。

## 7. 细胞补题方案(1505 → ~3000)

- 补题依据:细胞课件(PDF/DOCX)+ 丁明孝第五版(课件缺的按教材补)
- 补题顺序:每章重审完成后立即补(重审知薄弱点)
- 题量分配:按篇幅与考纲权重,每章补 40~90 题(56~119 → ~190)
- 题型结构:choice/truefalse 为主,multi 15-20%,short 10-15%,名解每章 15-20
- 查重:与全库(含生化)跨科查重 0 重复
- 备份:每章补题后更新"…细胞NN章优化版.html"
